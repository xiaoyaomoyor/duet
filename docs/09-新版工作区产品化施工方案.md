# 新版工作区产品化施工方案

日期：2026-09-20。核查基线：v0.10.0，提交 `6204754`。

状态：方案已确认，W1 已按本方案实施至 v0.11.0，详见 [W1 验收记录](10-W1工作区入口与迁移验收.md)。W2—W4 尚待实施。本文接续 R0—R5，调整产品入口、工作区定位与完成标准；不将已有功能重复列为新开发成果。

已确认：原有编辑视图与演示视图归为「旧版工作区」；新建舞台默认「新版工作区」；新版属于对奏现有主界面；样板间保留。旧版维持原有能力，新增能力集中新版；不支持切换时明确说明，保留全部数据。继续只开发 Web。

## 1. 本轮目标

让用户从对奏主页新建一个舞台，放入自己的素材，自由添加和组合模块，组织场景，进入演示视图播放，再返回编辑继续工作。保存、刷新、重新打开和交付工程之后，内容与演示组织仍然完整。

以「用户用自己的音乐完成一次评测」作为完成标准。新版应继承样板间的试听舞台和数据排版，同时具备旧版的实际创作能力。样板间的每种主要效果，都要能通过正式编辑器制作出来。

## 3. 产品结构与入口

### 3.1 统一概念

| 名称 | 含义 |
| --- | --- |
| 舞台 | 一份可保存、重新打开的完整对比工程；沿用现有 Project 数据身份 |
| 新版／旧版工作区 | 这份舞台采用哪套创作与呈现界面 |
| 编辑／演示视图 | 当前工作区的两种使用状态 |
| 场景 | 演示中的一页，可组合内容模块、选择版式并设置步骤 |
| 作品 | 某个参评对象的一份音乐、图片或其他产出，附带相关资料与评价 |
| 样板间 | 可预览、可复制使用的示例舞台集合 |
| 外观与版式 | 正式的用户定制入口 |

导航文案以「舞台」为主，避免「项目、舞台、兼容画布、剧场」同时充当同一层级的入口。工程文件继续使用现有格式。

### 3.2 主页与创建

- 保留对奏现有品牌、舞台列表、设置和当前舞台位置感；新版工作区进入现有主内容区。
- 首页提供明确的「新建舞台」「打开／导入」「样板间」入口，不新增第二个品牌首页。
- 新建可选音乐评测、图片评测、视频评测、通用对比和空白舞台，全部默认新版。音乐作为主要推荐项。
- 内容模板只决定初始模块与版式，不再隐式决定新旧工作区。
- 旧版入口放入舞台菜单中的「切换工作区」。不要让用户先挑一组名为兼容画布的模板才能理解两者关系。
- 旧舞台按原工作区打开；已有新版舞台继续新版。导入文件保留其工作区，复制舞台保留原选择；这些操作与「新建默认新版」区分处理。

### 3.3 切换规则

- 兼容舞台在同一项目内手动切换，保留项目 ID、素材、内容和各自布局配置。工作区切换不等同于内容转换或工程降级。
- 初次迁移旧数据保存可恢复快照；用户另存副本是独立、明确的操作，不再暗中由切换按钮决定。
- 首批可切换范围以旧版能够完整编辑的双对象、单测试题、单作品结构为基础，实施前通过能力检查固定具体条件。
- 多对象、多测试题、多作品等旧版无法完整承载的项目，不执行破坏性转换；显示具体原因，继续保留新版和全部数据。
- 新版场景步骤、外观等配置切到旧版时仍保留；旧版只呈现其支持的旧排版，返回新版可继续使用原配置。
- 切换前提交当前输入并处理保存失败；切换、返回、刷新、撤销和再次导出都需要验证。

## 4. 新版编辑器：让内容真正可制作

### 4.1 界面分工

编辑区采用三栏，画面优先：

- 左侧为场景列表，显示缩略图、标题、隐藏／待填写状态，支持添加、复制、排序与删除。当前场景就是准备演示的那一页。
- 中间是实际舞台预览。单击选择内容，双击或明确的编辑按钮打开编辑；播放、拖动进度等媒体操作不会被选择手势抢占。空场景提供可点击的添加入口。
- 右侧仅显示当前上下文，集中为内容、版式、外观。复杂歌词、长文、参数表使用统一的大编辑窗口。
- 作品库与参评对象管理使用同一侧面板的独立页面，不与属性栏重复叠放。关闭后恢复刚才的场景和选中内容。
- 顶部保持舞台名称、保存状态、撤销／重做和「开始演示」等主要操作。导出、工作区切换和低频管理进入清晰的次级菜单。
- 窄屏折叠侧栏以保证预览可读；演示视图隐藏编辑控件。桌面浏览器优先满足完整创作，小屏至少保证查看、播放和基础修改。

### 4.2 必须补齐的编辑动作

- 新增、编辑、复制、删除、隐藏模块；模块内排序、跨兼容位置移动；拖拽有按钮／键盘替代操作。
- 新增、复制、重命名、排序和隐藏场景；删除与复制明确说明影响范围。
- 支持对象各自内容和共享内容；不同对象可以有不同数量的模块，不能为了排齐而丢弃内容。
- 初始模板可自由增删、重排，不锁死为固定五页。
- 点击预览定位对应内容；空模块在编辑中可见、可填写，在演示中按明确规则隐藏。
- 所有内容修改进入现有命令与自动保存流程，支持撤销／重做；上传失败、存储失败和素材丢失具有明确反馈与重试入口。
- 「复制场景」默认复制相应可编辑内容；需要在多个场景复用同一作品或观察时，使用「引用已有内容」，在编辑器显示引用关系。
- 素材文件可复用同一存储资源，内容记录与样式不能因复制而意外共享可变状态。

音乐首批重点验收对象资料、音频、封面、歌词、文字／观察、参数表、评分、进度与结论。图片、视频和通用文字对比应能通过同一编辑框架完成基础流程；已有高级模块保留数据与原能力，按实际适配程度放入高级分组，不因新版重构而删除。

### 4.3 多作品的日常操作

- 沿用已有对象、测试题、作品模型和批量导入功能，把它们整合进易理解的入口。
- 音乐、封面、歌词、参数和评价明确属于哪一份作品；替换音频要提示核查时间相关歌词，避免沿用不匹配的同步信息。
- 单作品时简化控件；有多个作品时提供名称、封面与搜索，独立切换一个对象的作品不影响其他对象。
- 切换作品、测试题和场景时停止离场音源；缺少样本的对象显示真实缺项，不沿用上一题内容。
- 编辑中的选择与演示运行状态分开，返回编辑时恢复上下文；演示中的临时切换不擅自改写默认作品。

## 5. 把样板艺术风格变成可编辑版式

### 5.1 版式不是另一份内容

版式决定模块如何呈现，模块保存用户内容。换版式应重新编排现有内容，不清空文字或素材。版式不能容纳的内容仍在编辑器中列出，可调整位置或换用通用版式，禁止静默消失。

| 正式版式 | 样板风格落实方式 | 用户可编辑部分 |
| --- | --- | --- |
| 命题／开场 | 大标题、共同条件、错位封面与对象信息 | 标题、导语、条件、封面来源及对象 |
| 并置试听 | 有留白的封面、作品资料与克制播放器 | 作品、封面、说明、试听设置 |
| 作品＋观察 | 一侧媒体、一侧有层次的观察条目与引述 | 作品绑定、观察标题、正文、顺序与引用 |
| 数据对照 | 横向对齐的维度、数值、单位与简评 | 维度及其顺序、各对象数值、备注；缺项保持对齐 |
| 结论 | 主结论、适用场景及对象建议 | 结论、理由、推荐条件，支持没有胜者的结果 |
| 通用组合 | 共享区域、对象列和模块排列 | 自由选择和组合已有模块，承接非音乐内容 |

正式版式不依赖示例文案、固定 A/B 名称、特定指标键名或两张示例封面。实际项目、样板预览、编辑预览、演示及导出统一使用正式场景解析与渲染组件。

### 5.2 视觉与动效验收

- 保留墨色／纸色、衬线标题、精细分隔线、充分留白，以及试听舞台与编辑式数据表格的风格。沿用 R5 四套外观预设。
- 对象颜色主要服务识别、播放状态和数据强调，减少整块高饱和底色。六对象不依靠六块大色卡区别，文字标识始终清楚。
- 对象信息、作品名、模块标题和场景标题各有清晰层级，避免重复堆叠。
- 音频播放、聚焦、场景过渡和面板出现采用同一套动效节奏；尊重减少动态效果设置。内容过长时优先拆页或转阅读，不无限缩小字体。
- 所有弹窗、抽屉、表单、上传区、菜单及错误状态采用一致的间距、按钮层级和配色；设置、导入、导出等常用外围界面一起核查。
- 用真实用户形态内容验证：长工具名、不同封面比例、无封面、长歌词、空缺值、多个模块、六对象、超长结论。不能只验收精心挑选的演示数据。
- 固定画幅演示与小屏阅读分别适配；图片比例按用户选择处理，不能为凑齐布局强制裁掉作品。

## 6. 演示视图、样板间和组件规范

### 6.1 演示视图

复用已有演示运行态与快捷键，整合为连续流程：编辑当前场景 → 从当前页／从头演示 → 切页、显露、聚焦、切作品、试听 → 返回原编辑位置。

预览和演示使用同一内容与版式。演示状态只添加步骤、聚焦和控制条，不能在进入演示时突然换一种排版。界面明确显示控制状态，干净画面可录屏；退出全屏、退出干净画面和退出演示的顺序可预期，输入框内快捷键不抢占输入。

保留既有总览／重点双人／单项方式，并检查 2—6 对象下的作品切换、缺项、数据对齐和媒体独占播放。基础创作不要求用户先设置复杂步骤。

### 6.2 样板间

- 位于对奏主界面内，展示若干完整、可演示的示例舞台。
- 「预览样板」只读；「以此创建舞台」创建标准项目，生成独立 ID，并将所需素材可靠纳入项目资源。
- 同时提供「使用版式、清空示例内容」，保留结构和引导占位，防止示例评价混入用户作品。
- 样板使用与真实项目相同的数据格式、播放器与渲染器；每个样板都能在正式编辑器中还原。
- 创建后直接进入新版编辑视图，自动保存，出现在原有舞台列表。刷新后可继续编辑和播放。
- 示例音频与评价明确标注为示例；不把合成演示音频伪称为平台实测结果。素材沿用项目已有且可分发的资源。

### 6.3 「组件规范」的定位

当前页面展示颜色变量、字体层级、按钮状态和三档窗口，是开发与设计核查工具，目的是防止各处样式再次分裂。它本身不保存用户外观设置。

将其从普通用户的样板间主标签移至开发入口，名称为「设计规范」。用户定制继续使用「外观与版式」：项目风格、当前场景版式、字号层级与间距等受控选项、个人预设，以及已有的导入导出能力。用户无需接触 CSS 变量或内部组件名。

## 7. 技术施工边界

1. **显式工作区身份。** 为项目新增明确的工作区字段，例如 `workspace: 'modern' | 'legacy'`。视图继续由编辑／演示状态控制；`presentation.enabled` 作为旧数据迁移输入，不再作为外观开关兼任工作区身份。
2. **统一创建策略。** 项目工厂集中处理新建默认值、模板选择、复制、导入与旧数据迁移，防止不同按钮走出不同默认规则。
3. **单份内容。** 继续使用现有 comparison、作品、区段、模块和素材记录，旧 sheet 保持兼容投影。不要为新版复制一套无法同步的项目数据库。
4. **明确场景版式与引用。** 在现有场景上增加版式和内容绑定，支持从现有作品／模块组合媒体与观察；使用稳定 ID，不依赖数组下标、示例文本或临时 URL。缺失绑定在编辑中可定位修复。
5. **场景与来源分工。** 普通操作只需管理一份场景列表；内部继续保留内容来源，复制、复用、删除与默认样本变更通过统一命令更新相关引用。暂不强行抹平区段与演示场景的数据区别。
6. **同一渲染路径。** 从样板专用构图提炼正式可复用版式；`ProjectScene`、样板与导出共用同一套规则。旧版渲染器保留隔离边界，避免新样式污染旧项目。
7. **复用已有交付。** `.duet`、`.duetpack`、PNG、HTML 适配新增字段与版式；既有大小边界和不完整素材提示继续保留。外观预设仍只保存外观，不夹带作品。
8. **可追溯迁移。** IndexedDB、文件导入、校验器、快照和导出同步升级；先验证再落盘，不静默删除无法识别的数据。应用版本号与数据 schema 按实际变更分别管理。

## 8. 分阶段交付

按依赖顺序实施，每阶段完成相应验收后单独提交并推送；功能版本在阶段交付时提升，阶段内修正用补丁版本。W1 版本已落实；W2—W4 的版本为拟定。

| 阶段 | 核心工作 | 必须可演示的结果 | 拟定版本 |

## 9. 验收用例与放行条件

| 场景 | 通过条件 |
| --- | --- |
| 空白开始的音乐评测 | 无预填示例、无数据库注入，通过界面完成对象命名、真实音频与封面导入、歌词／观察／评分录入、模块组合、演示播放和再编辑 |
| 保存与重新打开 | 保存状态真实；刷新、关闭再开后内容、工作区、场景顺序及作品绑定正确；保存失败不显示为成功 |
| 复制与组合 | 模块和场景的独立副本不会联动原内容；显式引用则保持一致；移动、删除、撤销后无悬空引用或错绑作品 |
| 新旧工作区 | 历史舞台行为保持；兼容项目双向切换后数据完整；不兼容项目明确说明且不转换、不删减 |
| 样板转真实舞台 | 两种创建方式都写入正常项目列表；修改、刷新、重新打开、导出再导入均可用，不依赖样板页临时内存 |
| 模块自由组合 | 音频、图片、歌词、文字、参数和评分可混排；不因混入其他模块而丢失数据排版或隐藏内容；空内容有清晰编辑入口 |

| 多媒体类型 | 音乐完成重点验收；图片、视频、通用内容至少各完成一次从创建、编辑到演示、保存和导出的基础流程 |

验证沿用现有编码、类型、样式对比度、lint、单元测试、生产构建和浏览器测试。新增回归集中覆盖迁移、引用、保存、媒体切换与完整用户流程；不为单纯文案和间距变化堆叠无意义测试。

视觉检查覆盖 1920×1080、1366×768、1280×720 及约 390px 小屏。性能复用既有六对象、多作品夹具：作品界面切换约 300ms 内，持续切场景以 p95 帧间隔约 20ms 为目标，记录设备、生产构建、媒体节点与 URL 数量。R5 的场景往返 p95 36.4ms 是本轮待改善基线，不视为已达标；若无法达到，需明确保留未达标项与简化动效方案，不能用其他测试通过冲抵。

Edge／Chromium 与 Firefox 完成实际媒体和导出流程；Safari 的本地媒体、离线导出和素材包仍需 macOS／iOS 实机验证。现有 Windows WebKit 的存储与媒体限制不能代替 Safari 结论。在没有实机证据时，不宣称 Safari 全流程验收完成。详情沿用 [R5 验收记录](08-R5外观预设与交付验收.md)。

## 10. 范围控制

本轮优先完成新版的创作与演示闭环、真实内容的视觉质量和可靠保存。旧版只做维持兼容所需修复。继续暂缓桌面版、云协作、自动抓取平台、自动视频生成、完整音频工作站和任意坐标／CSS 编辑器。

「自由编辑」在本轮指自由增删与组合模块、调整场景和模块顺序、选择版式及受控布局外观；不把固定五页样板当成编辑器，也不将本轮扩展成需要用户自行排齐所有像素的设计软件。
