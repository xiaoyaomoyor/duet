## 本阶段边界

- 只读 HTML 使用原生音视频播放，不包含应用内同步控制、歌词联动或按键演示流程。未内嵌／内嵌失败的资源会在文件中明确提示，外链仍可能需要联网。
- 匿名范围是工具身份字段。工程文件 `.duet` 保留原始信息用于继续编辑；项目标题、备注和用户编写的正文不会被自动改写。界面提示已说明工程文件与分享结果的区别。
- 静态对比度检查通过不等于完成整站无障碍审计；本轮实际浏览器验证限于上述 Edge 环境，未宣称 Firefox／Safari 已验收。
- R1 的统一视觉系统与展示样板、后续多样本、按键演示、六方对比及布局定制按 [升级规划](02-Web体验升级规划.md) 推进。
